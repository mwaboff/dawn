A countdown is a number of segments counting down to something that is going to happen. Set how many segments it has, tick it down when its trigger fires, and when it hits 0 the thing happens.

When to tick

Standard
Tick down 1 every time a player makes an action roll.
Progress / Consequence
Tick by the roll's outcome, using the table below.
Long-term
